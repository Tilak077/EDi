## Product goal
Users build AI workflows on a drag-and-drop canvas. Unlike ordinary workflow tools, every connection between nodes must be an executable contract containing:
- expected input/output schema
- provenance/source requirements
- confidence threshold
- privacy classification
- freshness requirement
- token/cost budget
Before execution, the system validates the graph and explains invalid edges. During execution, it shows live node status, stores traces, pauses for human approval when needed, and re-runs only affected downstream nodes when an input changes.

MindWeave can now support multiple independent and interdependent workflows.

What was added:

- **Workflow Library** in the top bar  
  Save different workflows, such as:
  - Research workflow
  - Drafting workflow
  - Fact-check workflow
  - Safety/review workflow
  - Publication workflow

  Then load any saved workflow from the Library selector.

- **Branch** button  
  Creates a copy of the current workflow, so users can build variations without altering the original.

- **Workflow Module** node  
  Added under **Workflow orchestration** in the left palette. It lets a user use an entire saved workflow as one node inside another workflow.

Example structure:

```text
Topic Input
   ↓
Research Workflow Module
   ↓
Draft Workflow Module
   ↓
Fact Checker / Safety Guard
   ↓
Human Approval
   ↓
Final Output
```

- Module-to-module work remains contract-aware:
  - Receives a typed `topic`
  - Returns `draft`, `approved_draft`, or `final_output`
  - Carries confidence, privacy, freshness, and provenance
  - Records which workflow and execution created the output
  - Detects circular dependencies, so Workflow A cannot indirectly call itself through Workflow B

How to use it:

1. Create and **Save** your Research workflow.
2. Click **Branch** to create a new Drafting/Checking workflow, then save that too.
3. Create another orchestration workflow.
4. Drag **Workflow Module** from the left panel.
5. Select the node and choose a saved workflow from **Saved workflow ID** in the right panel.
6. Connect the modules using normal contract-aware arrows.

Important current MVP limitation: if a referenced workflow contains a Human Approval node, it must be approved independently before it can be used inside another workflow. This keeps human decisions clear and auditable.
